# Hand Gesture Recognition System

This project implements a real-time hand gesture recognition system using Mediapipe and a pre-trained deep learning model. It identifies hand gestures captured through a webcam and maps them to predefined classes for applications such as controlling devices, gaming, and more.

## Features
- **Real-time Gesture Recognition**: Uses Mediapipe for hand landmark detection and a deep learning model for gesture classification.
- **Pre-Trained Model**: Recognizes various hand gestures based on a custom-trained model.
- **User-Friendly Interface**: Displays the recognized gesture directly on the webcam feed.

## Requirements
- A webcam or external camera for capturing hand gestures.
- Python 3.7 or later with required libraries installed.
